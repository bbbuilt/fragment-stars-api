# Руководство по получению куков Fragment

Это руководство объясняет, как получить куки fragment.com для режима KYC (`0%` комиссии API).

## Что такое куки Fragment?

Куки Fragment — это токены аутентификации, которые подтверждают, что вы вошли в fragment.com. Когда вы предоставляете эти куки API, он может совершать покупки от вашего имени, используя ваш аккаунт Fragment.

## Зачем использовать режим KYC?

| Режим | Комиссия | Нужны куки | Предоплата |
|-------|----------|------------|------------|
| **No KYC** | **0,25%** | Нет | Да |
| **KYC** | **0% навсегда** | Да | Нет |

В режиме KYC комиссия API отсутствует, потому что покупки совершаются через ваш верифицированный аккаунт Fragment. Без KYC доступен простой режим с комиссией всего `0,25%`.

## Необходимые куки

Вам нужны эти 4 куки с fragment.com:

| Название куки | Обязательно | Описание |
|---------------|-------------|----------|
| `stel_token` | ✅ Да | Основной токен аутентификации сессии |
| `stel_ssid` | ✅ Да | ID сессии |
| `stel_ton_token` | ✅ **КРИТИЧНО** | Токен подключения TON кошелька - **обязателен для покупок** |
| `stel_dt` | ✅ Да | Смещение часового пояса (обычно `-180` или ваше локальное смещение) |

> ⚠️ **ВАЖНО**: Кука `stel_ton_token` **абсолютно необходима** для совершения покупок. Без неё покупки будут падать с ошибкой "кошелёк не подключён".

## Пошаговое руководство

### Шаг 1: Войдите в Fragment

1. Откройте браузер **Chrome** или **Edge** (рекомендуется)
2. Перейдите на https://fragment.com
3. Нажмите кнопку **"Log In"**
4. Авторизуйтесь через Telegram
5. Вы должны увидеть свой профиль в правом верхнем углу

### Шаг 2: Подключите TON кошелёк

**Этот шаг КРИТИЧЕН для получения куки `stel_ton_token`!**

1. На fragment.com нажмите кнопку **"Connect Wallet"**
2. Выберите ваш кошелёк:
   - **Tonkeeper** (рекомендуется)
   - **MyTonWallet**
   - **Tonhub**
3. Отсканируйте QR-код или используйте расширение браузера
4. Подтвердите подключение в приложении кошелька
5. Убедитесь, что кошелёк подключён (вы должны видеть адрес кошелька на fragment.com)

> 💡 **Совет**: Убедитесь, что кошелёк, который вы подключаете, имеет тот же адрес, что и seed-фраза, которую вы будете использовать в API!

### Шаг 3: Откройте инструменты разработчика

**Chrome/Edge:**
- Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux)
- Нажмите `Cmd+Option+I` (Mac)

**Firefox:**
- Нажмите `F12` или `Ctrl+Shift+K`

### Шаг 4: Перейдите к кукам

1. В DevTools нажмите вкладку **"Application"** (Chrome/Edge) или **"Хранилище"** (Firefox)
2. В левой боковой панели разверните **"Cookies"**
3. Нажмите на `https://fragment.com`

Вы должны увидеть список всех куков для fragment.com.

### Шаг 5: Скопируйте значения куков

Найдите и скопируйте столбец **Value** для каждой необходимой куки:

#### Пример:
```
Name                Value
----                -----
stel_token          1234567890abcdef...
stel_ssid           abcdef1234567890...
stel_ton_token      tonconnect_xyz123...  ← ДОЛЖНА присутствовать!
stel_dt             -180
```

> ⚠️ **Проверьте**: Если вы не видите `stel_ton_token`, вернитесь к Шагу 2 и подключите ваш TON кошелёк!

### Шаг 6: Создайте JSON файл

Создайте файл с именем `cookies.json` с такой структурой:

```json
{
    "stel_token": "вставьте_значение_stel_token_сюда",
    "stel_ssid": "вставьте_значение_stel_ssid_сюда",
    "stel_ton_token": "вставьте_значение_stel_ton_token_сюда",
    "stel_dt": "-180"
}
```

**Пример с реальными значениями:**
```json
{
    "stel_token": "1234567890abcdef1234567890abcdef",
    "stel_ssid": "abcdef1234567890abcdef1234567890",
    "stel_ton_token": "tonconnect_xyz123abc456def789",
    "stel_dt": "-180"
}
```

> 💡 **Примечание**: `stel_dt` — это смещение вашего часового пояса в минутах. `-180` = UTC+3 (Москва). Измените при необходимости.

### Шаг 7: Закодируйте в Base64

API ожидает куки в формате base64.

**Linux/Mac:**
```bash
cat cookies.json | base64 -w 0
```

**Windows PowerShell:**
```powershell
[Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes((Get-Content cookies.json -Raw)))
```

**Python:**
```python
import base64
import json

with open('cookies.json', 'r') as f:
    cookies = json.load(f)

encoded = base64.b64encode(json.dumps(cookies).encode()).decode()
print(encoded)
```

**Онлайн инструмент:**
- Перейдите на https://www.base64encode.org/
- Вставьте ваш JSON
- Нажмите "Encode"
- Скопируйте результат

### Шаг 8: Используйте в коде

```python
from fragment_api import FragmentAPIClient

client = FragmentAPIClient()

# Ваши закодированные в base64 куки из Шага 7
COOKIES = "eyJzdGVsX3Rva2VuIjoiMTIzNDU2Nzg5MGFiY2RlZiIsInN0ZWxfc3NpZCI6ImFiY2RlZjEyMzQ1Njc4OTAiLCJzdGVsX3Rvbl90b2tlbiI6InRvbmNvbm5lY3RfeHl6MTIzIiwic3RlbF9kdCI6Ii0xODAifQ=="

result = client.buy_stars(
    username="@telegram_user",
    amount=100,
    seed="your_seed_base64",
    cookies=COOKIES  # ← Ваши закодированные куки здесь
)

if result.success:
    print(f"✅ Успех! Режим: {result.mode}")  # Должно показать 'kyc'
    print(f"Ставка комиссии: {result.commission_rate * 100}%")
else:
    print(f"❌ Ошибка: {result.error}")
```

## Альтернативный формат: Массив объектов

API также принимает куки в формате массива:

```json
[
    {
        "name": "stel_token",
        "value": "ваше_значение_здесь",
        "domain": ".fragment.com",
        "path": "/"
    },
    {
        "name": "stel_ssid",
        "value": "ваше_значение_здесь",
        "domain": ".fragment.com",
        "path": "/"
    },
    {
        "name": "stel_ton_token",
        "value": "ваше_значение_здесь",
        "domain": ".fragment.com",
        "path": "/"
    },
    {
        "name": "stel_dt",
        "value": "-180",
        "domain": ".fragment.com",
        "path": "/"
    }
]
```

Этот формат полезен, если вы экспортируете куки из расширений браузера типа "EditThisCookie".

## Решение проблем

### Ошибка: "Недействительные или истёкшие куки"

**Причина**: Куки истекли или неправильно сформированы.

**Решение**:
1. Получите свежие куки с fragment.com
2. Убедитесь, что вы всё ещё авторизованы
3. Проверьте, что все 4 куки присутствуют
4. Проверьте правильность кодирования base64

### Ошибка: "Кошелёк не подключён"

**Причина**: Отсутствует кука `stel_ton_token`.

**Решение**:
1. Перейдите на fragment.com
2. Нажмите "Connect Wallet"
3. Подключите ваш TON кошелёк (Tonkeeper/MyTonWallet)
4. Получите свежие куки (включая `stel_ton_token`)

### Ошибка: "Пользователь не найден"

**Причина**: Имя пользователя Telegram не существует или неправильное.

**Решение**:
1. Проверьте правописание имени пользователя (без @)
2. Убедитесь, что у пользователя есть публичный аккаунт Telegram
3. Попробуйте с другим именем пользователя для теста

### Куки быстро истекают

**Причина**: Куки Fragment обычно истекают через 30 дней или при выходе из системы.

**Решение**:
1. Получайте свежие куки при необходимости
2. Храните куки безопасно
3. Реализуйте автоматическое обновление куков в вашем приложении
4. Рассмотрите использование режима No-KYC, если управление куками слишком сложное

## Лучшие практики безопасности

### ⚠️ НИКОГДА не делитесь своими куками!

Куки Fragment предоставляют **полный доступ** к вашему аккаунту Fragment. Любой, у кого есть ваши куки, может:
- Совершать покупки от вашего имени
- Получать доступ к вашему балансу Fragment
- Просматривать вашу историю транзакций
- Потенциально опустошить ваш аккаунт

### Рекомендации:

1. **Храните безопасно**: Используйте переменные окружения или зашифрованное хранилище
2. **Не коммитьте**: Добавьте `cookies.json` в `.gitignore`
3. **Регулярно обновляйте**: Получайте свежие куки каждые 30 дней
4. **Мониторьте использование**: Регулярно проверяйте ваш аккаунт Fragment
5. **Используйте отдельный аккаунт**: Рассмотрите использование выделенного аккаунта Fragment для доступа к API

### Пример `.gitignore`:
```
cookies.json
*.cookies
*_cookies.json
.env
```

## Срок действия куков

- **Типичный срок**: 30 дней
- **Истекают когда**: Вы выходите из fragment.com
- **Обновление**: Получайте новые куки при истечении

## FAQ

### В: Могу ли я использовать куки из мобильного браузера?

**О**: Да, но извлечь куки из мобильного браузера сложнее. Рекомендуется десктопный браузер.

### В: Нужно ли держать браузер открытым?

**О**: Нет, как только у вас есть куки, вы можете закрыть браузер. API будет использовать куки независимо.

### В: Могут ли несколько человек использовать одни и те же куки?

**О**: Технически да, но это не рекомендуется по соображениям безопасности. У каждого пользователя должен быть свой аккаунт Fragment и куки.

### В: Что если я не хочу предоставлять куки?

**О**: Используйте режим No-KYC вместо этого. У него выше комиссия, но не требуются куки:

```python
result = client.buy_stars(
    username="@telegram_user",
    amount=100,
    seed="your_seed_base64"
    # Нет параметра cookies = режим No-KYC
)
```

### В: Могу ли я автоматизировать извлечение куков?

**О**: Да, вы можете использовать инструменты автоматизации браузера, такие как Selenium или Playwright, для программного извлечения куков. Однако вам всё равно нужно будет обрабатывать начальный вход и подключение кошелька вручную.
